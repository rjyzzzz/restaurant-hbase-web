# 上海市餐饮空间分布与 HBase 存储可视化

基于课程项目《基于 HBase 的上海市餐饮消费画像》的交互式前端可视化站点：

- **78,018 条全量餐饮记录**：全部从 HBase 导出的 `hbase_export.jsonl` 打包加载，无抽样。
- **28 个菜系按色区分 + 多维筛选高亮**：支持行政区（17 区）、菜系、价位档、人均消费、点评数、有效样本过滤与自动视野定位。
- **空间机制地标圈**：内置宝山江杨市场（5 km）、浦东芦潮港（5 km）、外滩江海关大楼（1 km）、闵行古美公园（1.5 km）对照圈及实时区位商（LQ）计算。
- **HBase 数据模型检视**：点击地图任意点即可实时拆解 15 位 `RowKey`（区码 + 类码 + 反转消费 + 序号）、所属预分区 Region 及 3 个列族共 11 个 Cell。
